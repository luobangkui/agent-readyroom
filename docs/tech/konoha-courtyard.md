# 木叶庭院主题

## 目标和约束

将 `assets/concepts/konoha-office-v2/concept-empty.png` 的暖木、青瓦、障子窗、卷轴墙、庭院、茶歇角与柔和光照落实为可旋转的真实 Three.js 场景。新增可切换主题，保留旧主题。人物、任务状态、座椅/键盘接触、导航坐标沿用现有契约。

## 方案选择

1. 整图作背景：快，但视角、遮挡和人物行走无法匹配，不采用。
2. 整体生成 GLB：当前 Rodin 试验只生成中央桌椅，且为单网格，无法直接满足四人入座，保留作参考。
3. 模块化场景：沿用已校准的工位，替换建筑外壳和外围陈设，几何、木纹、纸面和光照由 Three.js 构建。选用此方案，支持现有实时交互且不引入服务依赖。

## 模块和数据流

- `themes/courtyard.js`：主题配色、光照及复用人物契约，id `konoha-courtyard`。
- `themes/courtyard-environment.js`：构建新建筑、屋檐、资料墙、花园、茶歇角及装饰。接口维持 `{root, update(time, night)}`。
- `office.js`：将旧外壳和外围陈设归组，在主题切换时控制可见性；四人工位、人物根节点及模型加载继续共用。
- `room-layout.js` 仍为交互坐标单一来源。新增实体家具保持既有障碍包围范围；外围景观放在可行走室内边界外。
- 静态几何按分区和材质合批，装饰缓存复用，避免切换重复构建。

## 验证和回滚

验证主题往返、昼夜、人物保持、工位到休息点路径、静态模型有限性、材质/批次数量及真实浏览器观感。默认将原木叶主题用户一次性迁移至新主题，其他主题偏好保留；用户仍可主动切回原木叶。无需后端重启。现有未提交改动不回退。
