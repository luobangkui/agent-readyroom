# 待命室主题与原始角色

当前可选主题：动漫待命室、暖木待命室、木叶 · Q 版火影。动漫与木叶共用「换人物」选择器：四个当前火影人物（自建鸣人，以及导入的三代目、纲手和小樱）及四个 Styloo 原作人物。切换这两种场景时保留成员外观、骨架和当前动作，老板默认纲手。

木叶场景保留日式木屋、灯笼、木叶标志和一乐拉面角，椅子与脚踏使用当前人物的办公动作校准。历史版 `konoha/naruto.glb`、`konoha/hiruzen.glb` 已从发布目录清理；旧身份 `naruto`、`hiruzen` 解析为对应的 `*-custom` 新模型。

## 原作角色

`../assets/styloo.js` 定义商人、学生、弓箭手、忍者四个模型，按任务成员顺序分配。后端会话 ID 不改变，角色不会因换主题而重建会话。原始 GLB 逐字节保留，贴图按作者建议使用 unlit 渲染。

任务少于四个成员时，余下工位可以展示尚未分配任务的场景同事；他们不进入后端任务/消息列表，也不显示虚构的执行状态。

## 动作接口

- `../assets/rigged-model.js`：克隆独立骨架、动画混合与起身后才移动的约束。
- `../assets/office-avatar.js`：加载竞态、模型切换、椅子校准、失败回退。
- `../../scripts/build-styloo-seating.mjs`：将 Quaternius 坐姿烘焙到 Styloo 骨架，修正 A/T 姿势差异，保留骨骼长度和手臂朝向。
- `../../ASSET-SOURCES.md`：来源、许可、原文件校验和交付范围。

重新构建：`node scripts/build-styloo-seating.mjs`、`npm test`、`npm run build`。

添加新的资源主题时提供 URL、原作动画名称、补充动作和椅子校准数据。不要直接沿用另一副骨架的节点名称或坐姿偏移；必须检查完整模型的站立和坐姿，而不仅是骨骼数值。
